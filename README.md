# Плагины БезКода Агента

Публичные установочные пакеты дополнительных плагинов [БезКода Агента](https://github.com/olegpavlich/bezcoda-agent).

| Плагин | Назначение |
|---|---|
| `@bezcoda/browser` | Браузер, инструменты работы с сайтами и ручной вход |
| `@bezcoda/communications` | Telegram и почта Агента |
| `@bezcoda/coordinator` | Задачи, рабочие сессии, результаты и расписания |

## Установка

1. Откройте [Releases](https://github.com/olegpavlich/bezcoda-agent-plugins/releases).
2. Выберите плагин и скопируйте ссылку на **`.tgz`** в Assets.
3. В веб-интерфейсе Агента: **Плагины → установить пакет → вставить ссылку**.

Скачивание публичное: токен GitHub на сервере не нужен. Все три плагина устанавливаются отдельно.
Архивы **Source code**, автоматически добавленные GitHub, для установки не подходят.

В релизе также находятся `delivery.json`, `SHA256SUMS`, CLI-помощник `install-*.mjs`
и `release.json` с совместимостью, ссылками и происхождением сборки.
Скачав архив, delivery.json и установщик в один каталог, можно проверить их:

```sh
sha256sum --check SHA256SUMS
```

Совместимость текущих пакетов: DSH `0.2.1-rc.3`, Node `24.14.0`, pnpm `11.28.5`.
Сервисный Агент должен предоставлять собственный менеджер пакетов.
Для браузера в Linux x64 нужны системные библиотеки Chromium и работающий sandbox;
сам Chromium подготавливается плагином. Полная нативная Linux-приёмка всех плагинов
ещё не завершена; публикация пакетов не снимает это ограничение.

Это репозиторий поставок. Разработка ведётся в закрытом GitLab.
Релизы самого приложения находятся в отдельном репозитории и обновляются независимо.
Лицензии и сведения об используемых компонентах включены в архивы плагинов.
